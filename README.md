## Орчин

- Үйлдлийн систем: Windows
- Команд ажиллуулах орчин: PowerShell
- `node -v` командын гаралт: `v25.5.0`

## Зорилго

«Уншлагын жагсаалт» аппыг SBTM аргаар судалж, бодитоор ажиглагдсан согогуудыг нотолгоотой баримтжуулах.

Туршилтын төлөвлөгөө: [charter.md](charter.md).

## Аппыг ажиллуулах

Нэмэлт сан суулгах шаардлагагүй. Репозиторийн үндсэн хавтсанд:

```powershell
node app.js
```

Браузераар http://localhost:3000 хаягийг нээнэ.

Серверийг `Ctrl+C` дарж зогсоогоод дахин ажиллуулахад өгөгдөл анхны гурван номтой төлөвт шилжинэ.

## Эх сурвалж
