## Аппыг ажиллуулах

Нэмэлт сан суулгах шаардлагагүй. Репозиторийн үндсэн хавтсанд:

```powershell
node app.js
```

Браузераар http://localhost:3000 хаягийг нээнэ.

Серверийг `Ctrl+C` дарж зогсоогоод дахин ажиллуулахад өгөгдөл анхны гурван номтой төлөвт шилжинэ.

## Дүгнэлт

Supermodel аяллаар BUG-01 тоолуур, BUG-02 оны формат, BUG-03 товчны өнгө гэсэн гурван согогийг богино хугацаанд илрүүлэв. Couch Potato болон дараах оролтын шалгалтуудаар BUG-04 дутуу талбар, BUG-05 давхардсан ном, BUG-06 оны хязгаарын согогуудыг баримтжуулав. Нэмэлт хайлтын шалгалтаар BUG-07 буюу том, жижиг үсэг ялгадаг зан төлөвийг батлав. Saboteur аяллаар буруу JSON хүсэлтэд HTTP 400 биш HTTP 200 буцаадаг BUG-09-ийг илрүүлэв. Charter-д тусгайлан заагаагүй Хуучин хувилбар холбоосыг дагахад BUG-08 буюу Internal Server Error гарсан.

Олон браузер болон зэрэгцээ хэрэглээний шалгалт энэ session-ийн тэмдэглэлд бүртгэгдээгүй тул дараагийн charter-аар эдгээрийг судална. Лаб 1-ийн [login.spec.ts](https://github.com/Zekken544/playwright-lab1-ui-tests/blob/main/tests/login.spec.ts) нь SauceDemo-ийн нэвтрэлт, сагсыг шалгадаг, [codegen-example.spec.ts](https://github.com/Zekken544/playwright-lab1-ui-tests/blob/main/tests/codegen-example.spec.ts) нь нэвтрэх үйлдэл гүйцэтгэдэг учраас эдгээр тестийг өөрчлөхгүйгээр Lab 7-ийн согогуудыг барихгүй. Уншлагын жагсаалтад зориулсан автомат шалгалт бичвэл BUG-01, BUG-04–BUG-09-ийн тоолуур, оролт, давхардал, хайлт, холбоос болон HTTP хариуг шалгаж болно. BUG-02, BUG-03-ыг энэ удаа нүдээр илрүүлсэн бөгөөд оны текст, товчны өнгийг тусгайлан шалгавал эдгээрийг мөн автоматжуулах боломжтой. AI туслахаас чиглүүлэг, баримтжуулалтын тусламж авч, аппын үйлдэл, бодит үр дүн болон дахин гаргах алхмуудыг өөрөө шалгасан.
